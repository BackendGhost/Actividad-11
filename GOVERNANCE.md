# Estándares del Proyecto Integrador - Librería ERP

## Definition of Ready (DoR)

Una Historia de Usuario está lista para desarrollo cuando:

- Tiene descripción clara en formato HU
- Tiene criterios de aceptación técnicos y medibles
- Está estimada en Story Points
- Tiene prioridad asignada
- No presenta dependencias bloqueantes

## Definition of Done (DoD)

Una Historia de Usuario se considera terminada cuando:

- El código fue revisado por al menos un compañero
- Se ejecutaron pruebas unitarias con éxito
- Cumple los criterios de aceptación
- Fue integrada a la rama principal
- Está documentada si corresponde
