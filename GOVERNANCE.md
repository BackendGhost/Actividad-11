# Estándares del Proyecto Integrador - Librería ERP

## 📝 Definition of Ready (DoR)
Una Historia de Usuario está lista para ser programada si cumple con:
* **Descripción Clara:** Formato "Como [rol], quiero [acción], para [valor]".
* **Criterios de Aceptación:** Tiene una lista de verificación (checklist) definida.
* **Estimación:** Tiene asignada una etiqueta de esfuerzo (ej. size: 5).
* **Priorización:** Tiene una etiqueta de prioridad (P1, P2 o P3).

## ✅ Definition of Done (DoD)
Una tarea se considera terminada (Done) solo cuando:
* **Código Limpio:** El código sigue los estándares de .NET y React.
* **Funcionalidad:** Cumple con todos los criterios de aceptación de la historia.
* **Revisión:** El código ha sido revisado y no presenta errores críticos.
* **Documentación:** Se han actualizado los diagramas o manuales si es necesario.
